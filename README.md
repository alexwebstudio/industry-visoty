# Индустрия высоты

Самостоятельный многостраничный сайт компании по промышленному альпинизму, фасадным работам и обслуживанию остекления.

## Запуск

```bash
npm ci
npm run dev
npm run build
npm run typecheck
```

Перед публикацией задайте `NEXT_PUBLIC_SITE_URL` в `.env.local` для отдельного домена проекта. Адрес сайта и домен Vercel здесь не зафиксированы.

Production-сборка запускается через Webpack: `npm run build`.

## Страницы

- `/` — главная;
- `/services` и `/services/[slug]` — направления и описания работ;
- `/about` — информация о компании;
- `/works` — предоставленные фотографии без неподтверждённых названий объектов;
- `/contacts` — телефон, WhatsApp и город;
- `/privacy` — демонстрационный текст политики, который нужно дополнить данными оператора перед публикацией.

Форма готовит текст обращения и открывает WhatsApp; сообщение уходит только после ручного нажатия «Отправить» в WhatsApp. Сайт не отправляет поля формы на собственный сервер.

Контактные данные взяты из предоставленной таблицы: «Индустрия высоты», Краснодар, +7 (988) 343-75-00. Адрес и email в исходных материалах отсутствуют. Фото взяты из переданной папки компании и используются без подписей с названиями, адресами или результатами конкретных работ.

## Стек

Next.js App Router, TypeScript, Tailwind CSS, GSAP, ScrollTrigger и Lenis. Сохранены анимации первого экрана, появления секций, параллакс, плавная прокрутка, мобильное меню, форма связи и переходы между страницами.
